# M1 Power Lab

This context names the durable scientific concepts used to investigate power-management behavior on an M1 target.

## Scientific investigation

**Hypothesis**:
A proposed explanation of an observed system behavior with predictions that distinguish it from alternatives.
_Avoid_: theory, guess

**Uninformative result**:
A valid experiment whose derived outcome is inconclusive under its frozen decision rule; an invalid experiment is not an uninformative result.
_Avoid_: failed experiment, negative result

**Redesign checkpoint**:
A recorded review of the experiment design required before repeating an explanation after two consecutive uninformative results for the same hypothesis.
_Avoid_: retry, rerun

**Procedure**:
An immutable, typed sequence of permitted operations that has passed validation and independent review before owner approval.
_Avoid_: plan, model recommendation
